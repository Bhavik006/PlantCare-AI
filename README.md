# 🌱 PlantCare AI

PlantCare AI is an AI-powered plant care assistant built with Python, Streamlit, and Google Gemini.

Users can upload a photo of their plant and ask questions about its condition. Gemini analyzes the image and provides practical plant-care guidance. Users can also generate a Plant Care Report and send it to their email.

## Features

- 🌱 Simple user onboarding
- 📷 Plant image upload
- 🤖 AI-powered plant analysis using Gemini
- 💬 Follow-up questions through chat
- 📋 Plant Care Report generation
- 📧 Send the report through Gmail
- 🎨 Clean Streamlit interface

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Gmail SMTP
